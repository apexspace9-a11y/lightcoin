# Light Coin

Light Coin là ứng dụng Android quản lý lịch cá nhân, mục tiêu tiết kiệm và nhắc hẹn trong một giao diện Material 3 gọn, hiện đại và ưu tiên dữ liệu cục bộ.

## Phiên bản cuối

**2.0.0+4**

## Chức năng

- Dashboard tổng quan lịch, lời nhắc và tiến độ tiết kiệm.
- Lịch tháng tiếng Việt, tạo/chỉnh sửa/xóa lịch và nhắc theo thời gian.
- Nhiều mục tiêu tiết kiệm, theo dõi tiến độ, nạp tiền, chỉnh sửa và xóa mục tiêu.
- Nhắc hẹn có bật/tắt, hoàn thành, chỉnh sửa, phân loại lời nhắc quá hạn.
- Notification Android có kiểm tra quyền ứng dụng và trạng thái kênh nhắc hẹn.
- Giao diện sáng/tối, haptic feedback và Material 3.
- Dữ liệu lưu cục bộ bằng SharedPreferences.

## Build

GitHub Actions chạy analyzer, tạo Android project sạch, build APK release và xuất artifact `LightCoin-APK`.
